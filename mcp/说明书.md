# MemGate MCP（D-MCP版）说明书

**一句话**：把治理级记忆（存取留痕/质量门/统计账）接到任何支持 MCP 的 AI 平台——
Claude Code、Cursor、Copilot Studio、Windsurf、Cline、Zed 一线全收。

## 它解决什么

AI 助手/编码代理的记忆各自为政：跨项目污染、无审计、忘得快。
MemGate MCP 提供**治理过的记忆存取**：每个条目带对象-动作-内容三元组签名，过质量门，入统计账。

## 快速开始

    # 1. 冒烟自测（应打印 SMOKE ALL GREEN）
    python3 test/test_mcp.py

    # 2. 接入宿主（以 Claude Desktop 为例，详见 config/mcp-config-examples.md）
    #    把配置 JSON 填入 claude_desktop_config.json，重启宿主

## 工具面（与 A-插件版/B-完整版同源语义）

- **memgate_deposit(obj, act, actual, kind, source)** — 存一条治理记忆
- **memgate_recall(query, top_k)** — 按签名/关键词召回（带分数）
- **memgate_stats()** — 记忆库统计
- **memgate_compact()** — 压实（清冗余）

## 环境

- Python >= 3.9，**零第三方依赖**（stdlib + 随包 kernel）
- MEMGATE_HOME：记忆库目录（默认 ~/.memgate-mcp）——多项目隔离=每项目配不同目录
- 与家族关系：kernel 单源同 B-完整版（sync_kernel.sh 链），生产改动回家族单源
