# MemSteward 完全本地版（C）· 说明书

> **一句话**：纯本地 LLM 记忆中间件 SDK——数据不出机器，pip 三行起步。

## 买家快速开始（10 分钟）

### ① 安装（1 分钟）

```bash
pip install ./sdk
```

### ② 三行用起来（2 分钟）

```python
from memsteward import Memory

mem = Memory('memory.json')
mem.deposit('player', 'mining', 'found diamond', kind='experience')
print(mem.recall('diamond'))
```

`deposit` 带质量门（回声碎片/超短自动隔离），`recall` 带 liveness 量门。

### ③ 时间线检索（1 分钟）

```python
print(mem.recall_recent(hours=24))   # 最近 24 小时
print(mem.recall_by_time(top_k=10))  # 按时间序
```

## API 面

| 方法 | 作用 |
|---|---|
| `Memory(path)` | 打开/创建本地记忆库（JSON 落盘，重启不丢） |
| `deposit(obj, act, actual, kind, source)` | 写一条记忆（对象/动作/结果） |
| `recall(query, top_k=5)` | 语义检索（混合检索，中文原生） |
| `recall_recent(hours, top_k)` | 最近 N 小时 |
| `recall_by_time(start, end, top_k)` | 时间段检索 |

需要更全的能力面（隔离检疫/蒸馏/概念空间等），用源码级 `src/memsteward_local.py` 的 `MemStewardLocal`（进阶，见 src 注释）。

## 数据与家

默认数据落在当前工作目录的 JSON 文件（`Memory('memory.json')` 显式给路径）；服务级部署（B 版）才涉及 `~/.memsteward` 家目录。
