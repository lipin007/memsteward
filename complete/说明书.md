# MemSteward 完全版（B）· 说明书

> **一句话**：多租户记忆服务后端——让任何 LLM agent 记得住、算得起、管得住；模型无关（API/本地/任意），自带鉴权、配额、计费、多租户隔离。

## 买家快速开始（10 分钟）

### ① 本地跑通多租户（2 分钟）

```bash
cd src
python3 -c "from cloud_api.tenant.manager import TenantStore; a=TenantStore('acme'); a.deposit('player','mining','found diamond'); b=TenantStore('globex'); print('acme:', a.recall('diamond')); print('globex(应为空):', b.recall('diamond')); print(a.stats())"
```

每个租户一个独立存储目录，**互相不可见**（上例 globex 查不到 acme 的记忆）。

### ② 起 REST 服务（5 分钟）

```bash
cd src/cloud_api
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
# 或容器化：docker-compose up -d
```

API 面（鉴权走 API key）：记忆读写、租户管理、配额/计费——完整参考见 `src/cloud_api/docs/api-reference.md`，多语言示例见 `src/cloud_api/examples/{curl,node,python}`，部署细节见 `src/cloud_api/docs/quickstart.md`。

## 产品构成

| 目录 | 内容 |
|---|---|
| `src/cloud_api/` | 多租户 REST 服务（FastAPI）：鉴权/配额/计费/租户管理 —— **未来收费线（云盘记忆存储）·当前预留种子，暂不部署/不上架**（2026-11-20 定位拍板）；不在三版本功能差内 |
| `src/kernel/` | 记忆核心装配（calldecay 存储引擎 + admission 质量门 + 蒸馏/衰减）——组件单源同步 |
| `src/vendor/` | 随包依赖（可再生，pack 脚本重建） |
| `config/` | 配置面 |
| `src/health_dashboard.py` | 运维健康看板（开发件） |
| `MANIFEST.md` | 装配清单（组件来源与状态） |

## 可选服务形态（组件 #26 daemon）

需要 web UI＋落地引擎常驻服务时，装上 daemon 组件（记忆体服务）：装进 B＝B 起服务，不装＝B 纯库栈。两态皆合法（组件既进组合也单卖）。
