# Contributing / 贡献

本项目暂不接受外部代码贡献。Issue 提案欢迎; 实现由项目方完成, 提案者获署名致谢。

This project does not accept external code contributions at this time. Issues
are welcome; implementation is done by the project team with credit to proposers.

⚠️ 请勿在公开 issue 中包含尚未获得专利申请日的技术主题——公开披露会摧毁其
新颖性。Please do not disclose not-yet-patented technical subject matter in
public issues; public disclosure destroys novelty.
