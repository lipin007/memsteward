# MemGate · 说明书

> **一句话**：OpenClaw 治理中间件插件——三层记忆（热/温/冷）＋治理工具面＋门禁，
> 业务逻辑单一来源在 Python 单源桥，TS 层只做调用面。

## 买家快速开始（10 分钟）

**① 取包解包（30 秒）**

```bash
tar -xzf memgate-2026.11.19.tgz && cd package
```

**② 直接用 Python 单源桥（2 分钟，无需接 OpenClaw）**

```bash
mkdir -p ~/.memsteward/landing
python3 src/bridge_cli.py deposit --landing ~/.memsteward/landing/landing.json --obj player --act mining --actual "found diamond"
python3 src/bridge_cli.py recall --landing ~/.memsteward/landing/landing.json --signature 'player|mining'
```

写入带质量门（admission：回声碎片/超短自动隔离），召回带 liveness 量门（冷条目不注入≠删除）。召回是**签名门控**：--signature 传 `对象|动作` 键（如 player|mining），不是自由词。

**③ 接入 OpenClaw（标准安装）**

```bash
openclaw plugins install ./memgate-2026.11.19.tgz   # 在买家机器执行
# 或一键：bash deploy/install.sh（装包→起守护→接线→自检；--skip-unit 可跳过 systemd）
```

装好后四个治理工具即可用：`governance_preflight` / `governance_ledger` / `governance_deposit` / `governance_recall`。

---
## 命名史（为什么叫 MemGate）

`governance-middleware`（11-03 骨架）→ `calldecacy`（11-04 装配）→ **`MemGate`**（11-05 产品大整理）。
与旧 CallDecay 是**两个逻辑的产品**（依赖关系非同源），改名彻底切分防混淆。

## 产品构成

| 目录/文件 | 内容 |
|---|---|
| `index.ts` / `src/*.ts` | 插件面：context-engine（三层记忆）、memory-capability（账本摘要）、tools（治理四件） |
| `src/bridge_cli.py` | **Python 单源**（业务逻辑全在此）：CLI/oneshot/serve 三形态，常驻 worker 崩溃自愈 |
| `src/vendor/` | 构建产物（pack.sh 随包）：calldecay-sdk＋core＋pvs-sdk——**依赖库，可再生** |
| `assemble.sh` / `pack.sh` | 一键装配核对（语法→版本绑定→回归套件→preflight；套件规模以运行输出为准）/ npm 制品打包 |
| `_legacy/` | 前身 governance-middleware 备份（留痕） |

## 工具与接口

- **治理工具四件**（TS 面）：`governance_preflight` / `governance_ledger` / `governance_deposit` / `governance_recall`
- **bridge 子命令**（13 个）：deposit / recall / digest / ingest / commit / preflight / ledger / constraints / depscan / version / compact / restore / ping
- **槽位**：`plugins.slots.memory=memgate`、`contextEngine=memgate`（openclaw.json）

## 依赖（vendor 来源）

| 依赖 | 来源 | 用途 |
|---|---|---|
| calldecay-sdk | `../CallDecay/sdk/calldecay` | LandingStore 存储引擎（硬落盘/签名门控召回/回放） |
| core | `../CallDecay/core/` | accept_contract（F1/F3 边界） |
| pvs-sdk | `../pvs-sdk/` | pvs.gate 门禁/台账/治理纪律面 |

**与旧 CallDecay 的关系＝依赖，不是同源**：本插件碰决策环 0 处（5 源文件 grep 全零实证）。

## 运维

- 装配核对：`bash assemble.sh --write`；制品：`bash pack.sh`
- 数据目录：`$MEMSTEWARD_HOME/landing/landing.json`（默认 `~/.memsteward/`；`~/.calldecacy` 为部分 kernel 辅件的**旧默认兜底**，env 覆盖或显式传参即绕过，生产全走显式路径——2026-11-20 实测修正）
- 发布红线：pack.sh 产物＝内部/同机分发；公开发布走《发布物排除清单》六门
